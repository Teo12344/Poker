# ♠ Home Game — 친구들과 하는 텍사스 홀덤

설치할 패키지가 없습니다. **Node.js 18 이상**만 있으면 됩니다.

## 실행

```bash
cd poker
node server.js
```

터미널에 주소가 나옵니다.

- 내 컴퓨터: `http://localhost:3000`
- 같은 와이파이의 친구: `http://192.168.x.x:3000` (터미널에 표시된 주소)

포트를 바꾸려면 `PORT=8080 node server.js` 처럼 실행하세요.

## 고정 주소로 올리기 (Render 무료)

1. github.com 가입 → 오른쪽 위 **+ → New repository** → 이름 `poker` → Create
2. "uploading an existing file" 클릭 → 이 폴더 안의 파일과 `public` 폴더를 통째로 끌어다 놓기 → Commit
3. render.com 가입 (GitHub로 로그인) → **New → Web Service** → `poker` 저장소 선택
4. Build Command는 비워 두거나 `npm install`, Start Command는 `node server.js`, Instance Type은 **Free** → Deploy
5. 몇 분 뒤 생기는 `https://poker-xxxx.onrender.com` 주소가 우리 사이트입니다

무료 플랜은 15분 동안 아무도 접속하지 않으면 잠들고, 다음 접속 때 깨어나는 데 30초~1분 걸립니다. 잠들거나 재시작되면 칩은 초기화됩니다.

## 내 컴퓨터에서 켜고 멀리 있는 친구와 하기

서버를 켠 상태에서 터미널을 하나 더 열고 아래 중 하나를 실행하면 인터넷 주소가 생깁니다.

```bash
npx cloudflared tunnel --url http://localhost:3000   # 가입 필요 없음
# 또는
ngrok http 3000
```

나온 `https://...` 주소를 친구들에게 보내면 됩니다. 계속 켜 두고 싶다면 Render나 Railway 같은 Node 호스팅에 이 폴더를 그대로 올리면 됩니다 (시작 명령: `node server.js`).

## 게임 규칙 / 기능

- 노리밋 텍사스 홀덤, 최대 6명, 모두 **$50,000**으로 시작, 블라인드 $250 / $500
- 카드는 서버에서만 섞고 나눕니다. 각자 브라우저에는 **자기 카드만** 전송됩니다 (쇼다운 또는 올인 시에만 공개)
- 체크 / 콜 / 벳 / 레이즈 / 올인, 최소 레이즈 규칙, 숏 올인 시 레이즈 재오픈 금지, 사이드 팟, 스플릿 팟, 헤즈업 블라인드 규칙
- 딜러 버튼 자동 이동, 다음 핸드 자동 시작
- **승률 표시**: 내 패와 깔린 보드로 매 스트리트마다 다시 계산 (프리플랍 → 플랍 → 턴 → 리버 변화 기록). 올인으로 모든 패가 공개되면 실제 패 기준으로 정확히 계산하고, 각 플레이어 머리 위에 승률을 표시
- 차례마다 30초 제한 (초과 시 자동 체크/폴드, 두 번 연속이면 자리 비움 처리)
- 단축키: `F` 폴드, `C` 체크/콜, `R` 레이즈
- 방 이름을 다르게 하면 테이블을 여러 개 만들 수 있음 (`/?room=이름`)
- 게임 내 구매 없음. 칩을 다 잃으면 무료로 $50,000을 다시 받을 수 있음
- 새로고침해도 자리가 유지됨. 서버를 껐다 켜면 칩은 초기화됨 (메모리에만 저장)

설정값(시작 칩, 블라인드, 제한 시간)은 `game.js` 맨 위 `CFG`에서 바꿀 수 있습니다.

## 파일 구성

```
server.js        HTTP 서버 + 실시간 전송(SSE)
game.js          게임 규칙 엔진 (서버 쪽, 카드 관리)
public/
  index.html     화면
  style.css      테이블 디자인
  app.js         화면 로직, 승률 계산
  eval.js        족보 판정 + 승률 계산 (서버/브라우저 공용)
```
